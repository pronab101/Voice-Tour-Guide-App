# Voice Tour Guide App

A Flutter-based mobile app that uses TensorFlow Lite and Hugging Face to recognize landmarks and provide real-time AI-powered audio guidance.

## Features
- Real-time landmark detection using camera
- TensorFlow Lite model for classification
- Hugging Face LLM integration for conversational guidance
- Flutter + Hugging Face backend

## Tech Stack
Flutter, Dart, TensorFlow Lite, Hugging Face, Python (for model prep)
